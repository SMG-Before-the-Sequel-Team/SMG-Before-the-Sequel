# SilentRealmEntrance

The Entrance into the Silent Realms from The Legend of Zelda: Skyward Sword is now in SMG2!

Due to using `NameObjFactory`, no `ProductMapObjDataTable` entries are required for this module to function properly.

This object has no sounds or particles with it.


This object has gotten some new Obj_Args and Switches.
---
Obj_Arg0: Controls what index of ChangeSceneListInfo gets used  
Obj_Arg1: What Color Frame is used

---

### Switches
SW_AWAKE: Works as most instances as SW_AWAKE are in the base game.
