# SMG2_SpaceCocoon
Sling Pods in Galaxy 2!

Below is a list of everything that's included:
- The ObjectData archive for Sling Pods and some Mario animations.
- JSON files for particle effects.

Below is a list of other things that you will need:

- A level editor.
- A Effect JSON supported particle editor.
- A UseResource file with Sling Pod related sound labels.

## Setup
It is adviced to reference the template mod for this port. Regardless here are some parameters that apply to Sling Pods.

### SpaceCocoon
| Parameter | Description |
| --- | --- |
| Obj_arg0 | Flight time in frames. |
| Obj_arg1 | Length of the stem. |
| Obj_arg2 | (Bool) Activate SW_A after use? |
| SW_A | Activated after first use when Obj_arg3 is set. Can be either the player or a Toad. |
